Squarb settings

Remap any key. Changes save as you type and apply to open tabs straight away.

Prefix keys

Press a prefix, then a target key. The defaults use brackets for direction: ] next, [ previous.

Target keys

One character per key. Separate several keys with spaces, as in j f. Leave a field empty to unbind it.

The uppercase version of the button and link keys is the loose variant (]B, ]L): it also stops on elements that only look clickable. It follows your binding, so if buttons are on u, ]U is the loose one. If you bind an uppercase key here, your binding wins.
